# Claims and their evidence

Every public statement about CHAIR carries a tier:

- **REPRODUCIBLE**: run the command and get the same result.
- **VERIFIED-LIVE**: a public on-chain artefact you can open or query.
- **MODELED**: computed by the simulation from recorded inputs, not observed on a live market.
- **NOT-CLAIMED**: we deliberately do not claim it.

Commands that use `view` assume the helper from [JUDGES.md, step 0](JUDGES.md#0-set-up-one-helper-10-seconds), and `mview` its mainnet twin from [JUDGES.md, mainnet](JUDGES.md#mainnet-read-meeting-1-1-minute). Transactions are on NEAR testnet unless the row says mainnet.

## What is simulated, and what is a stand-in

- **token3's chair** is the test signer (`test-signer/`). It plays a deterministic chair that obeys any petition telling it to ignore the constitution, and signs with a test key on token3's `model_signers`. It exists to exercise the clamp on a ruling a real model would not return. token5's chair is NEAR AI's GLM 5.3 Flash (claim 33).
- **The testnet allowlists** of token4 and token5 also hold the test keys, so the site's playground can sign rulings a real model never would. Mainnet's allowlists hold only NEAR AI's verified keys (claim 48).
- **The testnet farm** is `mock-farm/`, with the same methods, arguments and gas floors as `stake.dao`.
- **The simulation's models** ran on Venice under the same model families as the IQ ladder, with the contract's exact request bytes. The hosts differ from NEAR AI's.
- **The simulation's holders, scenarios and PID controller** are ours, described in [`docs/SIMULATION.md`](docs/SIMULATION.md).
